# Legacy workflow arquivado

Estas skills pertencem ao workflow anterior que criava e executava `SPEC-FIX`, `DESIGN-FIX`, `TASKS-FIX`, `EXECUTION-FIX`, `REGRESSION-FIX` e `VERIFICATION-FIX`.

Elas foram retiradas de `skills/` na V2 para evitar duas fontes de verdade e conflito com o Spec Kit oficial.

Conteúdo preservado para:

- auditoria;
- leitura de artefatos antigos;
- migração gradual;
- eventual restauração manual se o time decidir não usar Spec Kit.

Não copie esta pasta para `.github/skills/` junto com a V2, a menos que você queira deliberadamente reativar o workflow antigo.
